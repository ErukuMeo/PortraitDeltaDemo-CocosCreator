### 验证方法

1. **编辑器预览**：在 CC 2.4.9 编辑器中运行 `PortraitDemo` 场景，手动操作所有按钮交互
2. **Console 日志**：在关键路径（加载开始、解析完成、纹理创建、渲染完成）输出 `cc.log()` 日志，确认执行路径
3. **目视检查**：对比 pdpack Python 工具 `preview` 命令输出的重建图，确保 CC 渲染结果一致
4. **异常路径**：提供错误的文件路径/非法文件，验证错误处理
