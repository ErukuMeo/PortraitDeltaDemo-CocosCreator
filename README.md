# Portrait Delta Pack - Cocos Creator Demo

此项目用于演示[Portrait Delta Packer](https://github.com/ErukuMeo/PortraitDeltaPacker)在`CocosCreator 2.4.x` 中的使用。包含`CocosCreator Runtime`层、`pdpack-importer`扩展插件支持 以及演示场景

1. 用 Cocos Creator 打开本项目
2. 打开预览场景 `Scene/PortraitDemo`
3. 运行编辑器预览
