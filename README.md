# Portrait Delta Pack - Cocos Creator Demo

此项目用于演示[Portrait Delta Packer](https://github.com/ErukuMeo/PortraitDeltaPacker)在`CocosCreator 2.4.x` 中的使用。包含`CocosCreator Runtime`层以及演示场景

2. 搭建演示场景（参考 `docs/tasks/T5-DemoScene.md` 中的布局说明）
3. 或直接运行编辑器预览
